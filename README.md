# R Scripts - Bio analyses

These R scripts can be used for analyzing motility assays, bacterial growth curves, and bacteriophage infection experiments.

## 📂 Structure

- `scripts/`: All R scripts.
- `data_example/`: Example datasets (CSV files).
- `figures/`: Example plots generated from the scripts.

## 🚀 How to use

1. Download the repository.
2. Open the script you want in RStudio.
3. Replace the example data with your own.

## 📊 Scripts included

- `motility_analysis.R`
- `growth_curve.R`
- `phage_infection.R`
